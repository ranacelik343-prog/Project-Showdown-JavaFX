# Project Showdown - JavaFX Memory Game

A cognitive memory matching game built with Java and JavaFX. The game features multiple difficulty levels, a countdown timer, and a persistent high-score system.

## 🚀 Features & Technical Details
* **UI/UX & Animations:** Custom JavaFX GUI featuring 3D card flip animations using `RotateTransition`.
* **Game Engine:** Independent game logic separating UI from core mechanics (MVC pattern approach).
* **File I/O:** Persistent High-Score tracking using standard Java I/O (`BufferedWriter`, `BufferedReader`).
* **Asynchronous Tasks:** Background timer operations implemented via JavaFX `Timeline`.

## 🛠️ Technologies Used
* Java 
* JavaFX (GUI, Media, Animations)
* Object-Oriented Programming (OOP)
